# Employee Management System

A comprehensive, responsive web application for managing employees, departments, attendance, performance, payroll, and leave requests.

![Employee Management System](https://img.shields.io/badge/Status-Production%20Ready-success)
![License](https://img.shields.io/badge/License-MIT-blue)

## Features

### 📊 Dashboard
- Real-time statistics (total employees, present today, on leave, departments)
- Recent employees overview
- Attendance charts and metrics

### 👥 Employee Management
- Add, edit, delete employees
- Filter by department and status
- Search functionality
- Detailed employee profiles
- Employment type tracking (Full-time, Part-time, Contract, Internship)

### 🏢 Department Management
- Create and manage departments
- Assign department heads
- Track employee count per department
- Budget management

### ✅ Attendance Tracking
- Daily check-in/check-out
- Late arrival detection
- Absentee tracking
- Hours worked calculation

### 📈 Performance Reviews
- Quarterly performance scoring
- Top performers ranking
- Performance distribution charts
- Review comments and feedback

### 💰 Payroll Management
- Salary breakdown (basic, allowances, deductions)
- Net salary calculation
- Payment status tracking
- Payslip generation

### 🏖️ Leave Management
- Multiple leave types (Sick, Casual, Annual, Maternity)
- Leave balance tracking
- Approval workflow
- Leave history

### 📑 Reports
- Attendance reports
- Performance reports
- Payroll reports
- Department-wise analytics
- Employee directory exports

### ⚙️ Settings
- Company configuration
- User management
- Notification preferences
- Data backup and export

## Tech Stack

- **HTML5** - Semantic structure
- **CSS3** - Modern styling with CSS Grid, Flexbox, and custom properties
- **JavaScript (ES6+)** - Interactive functionality without frameworks
- **Font Awesome** - Icon library
- **Vercel** - Hosting and deployment
